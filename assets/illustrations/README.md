# Supplied illustration assets

These transparent PNGs are raster exports of the original avatar SVG artwork inside the supplied HTML mockups. They are sample outfit illustrations, not user photos or generated try-ons.

- navy, rust, cream, green: the four figure SVGs in design-reference/screens/Main.dc.html, in source order.
- ivory: the second figure SVG in design-reference/screens/Closet.dc.html.

Export resolution: 600 × 700. Original viewBox: 120 × 140. No HTML/runtime scripts are used in the application.
